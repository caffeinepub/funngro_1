# Specification

## Summary
**Goal:** Build a 2-page, responsive Funngro (Teen) marketing site with newly authored, SEO-friendly English content and a cohesive teen-focused visual theme.

**Planned changes:**
- Create exactly two primary pages/routes with top navigation and clear cross-page CTAs.
- Page 1 (Teen Landing): hero with primary CTA, key benefits, “How it works” overview, trust signals (stats/short quotes), and repeated CTA near the bottom.
- Page 2 (Teen Details): deeper steps, eligibility/requirements, safety/trust explanation, FAQs, and a secondary CTA, with internal links back to Page 1 and within-page navigation as needed.
- Add SEO-ready structure on both pages: unique titles and meta descriptions, configurable canonical strategy, semantic/accessible markup with one H1 per page and scannable H2/H3 hierarchy.
- Apply a consistent, non-blue/purple-forward design system (typography, spacing, buttons, section patterns) with clear hover/focus states.
- Add and render static generated marketing images from `frontend/public/assets/generated`, including descriptive alt text.

**User-visible outcome:** Visitors can navigate a polished, mobile-friendly 2-page Teen marketing site for Funngro, read SEO-oriented content about teen freelancing and paid projects for teens, and follow clear CTAs between the landing and details pages.
